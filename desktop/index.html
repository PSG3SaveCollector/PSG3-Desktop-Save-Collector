STEP 1 / START

How the save collector works

This tool helps you prepare your old and new Pixel Survival Game 3 character saves for a migration or edit.

  1. Enter your player name and character slot, then start.
  2. Connect your phone by USB and copy the OLD .es file. The tool saves a verified backup in Downloads.
  3. After confirming your backup, follow the in-game instructions to create a NEW character in the same slot.
  4. Collect the new .es file and click Submit. Both files are packaged together and sent to the private submission destination.

Original phone files are not changed by this tool. Do not reset a character unless you have checked its backup.

STEP 2 / OLD SAVE

Extract and back up the OLD character

Keep the old character on the phone until the backup has been copied and verified on your PC.

Find your OLD .es file

  1. Connect your phone to your PC using a USB cable and unlock it.
  2. On the phone, choose USB file transfer (MTP), not charging only.
  3. In Windows File Explorer, open This PC → your phone → Internal shared storage.
  4. Go to Android\data\com.cowbeans.pixelsurvival3\files.
  5. Select your character's file: Slot 1 d.es, Slot 2 d2.es, or Slot 3 d3.es.

If the file picker cannot open Android/data, first copy the .es file to a folder on your PC. Some Android phones restrict access to this folder over USB. Never reset the character until the backup below has been verified.

The backup will be created automatically in Downloads → PSG3 Collector Backups and checked before you continue. If the file picker cannot browse the phone, copy your .es file to the PC first.

No old save backed up yet.
STEP 3 / GAME SETUP

After backup: create a NEW character

Deleting a character slot can be irreversible. The collector never deletes game data. Do not continue until the backup ZIP exists on your PC and you've checked that it can be opened. Keep a second copy somewhere safe.
  1. Open the backup folder and verify BACKUP_OLD_Slot*.zip exists and contains OLD/character.es.
  2. Only then, on the phone, delete/reset the chosen character slot manually in the game.
  3. Create a new character in the same slot and complete the new-account setup.
  4. Join a multiplayer world that loads correctly, allow the character to save, then exit the game.
  5. Keep the USB connection active to retrieve the NEW .es file.
STEP 4 / NEW SAVE

Extract the NEW working character

From the same slot on the newly created character, select the new .es file. The app keeps both saves separately.

Find your NEW .es file

  1. Connect your phone to your PC using a USB cable and unlock it.
  2. On the phone, choose USB file transfer (MTP), not charging only.
  3. In Windows File Explorer, open This PC → your phone → Internal shared storage.
  4. Go to Android\data\com.cowbeans.pixelsurvival3\files.
  5. Select your character's file: Slot 1 d.es, Slot 2 d2.es, or Slot 3 d3.es.

After the new character has saved and exited, select its .es file. If Android/data is inaccessible, copy the new file to your PC first. Keep your verified old backup untouched.
